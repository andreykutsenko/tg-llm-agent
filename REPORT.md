## Отклонения от ТЗ

Зафиксированы агентом, все обоснованы:

1. **venv создан через `uv`**, а не `python3 -m venv` — в системе отсутствует пакет
   `python3.13-venv` (`ensurepip is not available`). На `requirements.txt` не влияет,
   но у отклонения есть последствие, замеченное уже при ревью: **созданное `uv`
   окружение не содержит `pip`**, это его штатное поведение. Инструкция вида
   `pip install -r requirements.txt` внутри такого окружения падает с
   `No module named pip`. README исправлен: приведены оба способа установки,
   и отдельно объяснено, что делать при этой ошибке.
2. **Добавлен `llms/errors.py`** сверх списка модулей ТЗ — иначе `llms/__init__.py`
   и провайдеры образуют круговой импорт.
3. **Установились свежие мажоры SDK** (`openai` 3.3.1, `anthropic` 1.0.0),
   тянущие `httpx2` вместо `httpx` — в тесте таймаута импорт с фолбэком.

## Правки после ревью

Ревью кода отдельным проходом, как и в предыдущем задании. Найдено и исправлено:

1. **`LLM_MAX_TOKENS=512` ломал облачный профиль.** У `claude-opus-5` размышление
   включено по умолчанию, и его токены расходуют тот же лимит вывода. При 512
   ответ мог оказаться пустым: текстовых блоков в ответе не осталось бы,
   и бот сообщил бы «Модель вернула пустой ответ». В профиль Anthropic
   добавлено `LLM_MAX_TOKENS=4096` с объяснением.
2. **Инструкция по установке не работала в собственном окружении проекта.**
   README предлагал `pip install -r requirements.txt`, но в созданном `uv`
   окружении `pip` отсутствует. Проверяющий упёрся бы в это первым же шагом.
   Добавлены оба способа установки и объяснение ошибки.
3. **Незакрытый `<think>` не вырезался.** Регулярное выражение искало пару тегов,
   но обрыв по лимиту токенов оставляет открывающий тег без закрывающего —
   пользователь увидел бы сырое размышление модели. Добавлена обработка
   и два теста (20 → 22).

## Что проверено, а что нет

**Проверено:** установка зависимостей, импорт всех модулей, сигнатуры SDK,
полный прогон `pytest` — 22 теста зелёные, сеть не используется.

**Не проверено на момент генерации:** живой ответ в Telegram, локальная Ollama,
облачный Anthropic — в окружении генерации не было ни токена, ни ключа,
ни установленной Ollama. Оба провайдера покрыты моками.
